# 🥚 Layers ROI Studio

**Decisions based on ROI**

Layers ROI Studio is an interactive decision-support tool designed to quantify the financial impact of feed additives and management interventions in commercial laying hens.

The application transforms biological performance improvements into clear economic outcomes by integrating egg production, egg quality, mortality reduction, feed consumption, additive investment, and market prices into a single ROI framework. 

---

## Overview

Determining the economic value of nutritional and health interventions can be challenging when biological responses are measured across multiple performance indicators.

Layers ROI Studio helps nutritionists, veterinarians, researchers, technical managers, and commercial teams answer one key question:

> **Does the value generated by improved flock performance justify the investment?**

The tool estimates both per-flock economic impact and return on investment (ROI) using a transparent production and mortality model.

## Methodology

The model combines three major value drivers:

### 1. Increased Egg Production

Additional laying rate increases total egg output during the selected production period. 

### 2. Increased Sellable Eggs

Higher egg quality increases the proportion of eggs that generate revenue. 

### 3. Mortality Reduction

Improved liveability results in:

- More hens remaining in production
- Additional eggs produced by saved hens
- Additional revenue generation

using a mortality distribution model across the production cycle. 

### ROI Formula

```text
ROI = Incremental Net Benefit ÷ Additive Investment
```

Where:

```text
Incremental Net Benefit =
(Revenue With Additive − Additive Cost)
− Revenue Without Additive
```

An ROI of:

- 0 = Break-even
- 1 = 100% return
- 2 = 200% return
- >2 = High-value investment
